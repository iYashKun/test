Round Independence

Every round is generated independently. The result of the previous round is not used to calculate the next result.

🔍 How the random crash point works

This demo creates a fresh random value u between 0 and 1 for every round. That value is then transformed into a multiplier.

u = random(0, 1)

raw = 1 + (-ln(1 - u) × 2.5)

crashPoint = min(raw, 100)

The logarithmic transformation means lower multipliers occur more frequently while larger multipliers become progressively less frequent.

🛡 Transparency & limitations

The game does not manually choose a crash point based on your bet, previous result, or cash-out action. Everything happens locally in this demo.

⚠ DEMO LIMITATION

This version uses the browser's Math.random(). It is suitable for a visual/demo project but is not cryptographically secure and is not a provably-fair gambling implementation.

For a real production fairness system, use a server-side cryptographically secure RNG and publish an independently verifiable commitment/proof scheme.
