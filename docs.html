ENVIRONMENT VARIABLES

Zero-config deployment

Variable Purpose
TG_API_IDTelegram API ID (required for Pyrogram)
TG_API_HASHTelegram API Hash (required for auth)
SESSION_STRINGPersistent session (optional but recommended)
TARGET_BASE_URLRemote raw-file proxy (optional)
KEEPALIVE_URLPing to keep container alive
PORTDefault 8962

MEDIA PREVIEW ENGINE

How /api/v2/raw works

Two intelligent modes:

  1. Mode A — TARGET_BASE_URL defined: requests are forwarded to your remote raw proxy
  2. Mode B — No proxy: local Pyrogram userbot downloads and streams instantly
SECURITY & MONITORING

Session Security

Monitoring

/health endpoint + KEEPALIVE_URL for zero-downtime deployments on any cloud.
