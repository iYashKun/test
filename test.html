Why EVM

Simple by design.

Everything you need to generate EVM wallets locally, without a blockchain connection or external API.

⚡

Fast

Built with Zig and a reusable thread pool for high-throughput wallet generation.

⌘

Local

Wallet generation happens entirely on your machine. No RPC. No API. No network required.

◈

Crypto-native

Uses OS randomness, OpenSSL secp256k1 and Ethereum Keccak-256.

Generation modes

Three ways to generate.

Pick the mode you need. Every run starts from a simple interactive CLI.

01

Normal

Generate completely random EVM wallets with secure private keys.

--count 1000
02

Vanity

Search for addresses matching up to 10 hexadecimal characters.

0xdead...
03

Exclusion

Generate addresses while excluding selected hexadecimal characters.

b,6,f
Documentation

Get started in seconds.

Install the dependencies, build the project and start generating wallets from your terminal.

Installation 
git clone https://github.com/iSreyanshu/Wallets.git

cd Wallets

chmod +x install.sh run.sh

Manual build 
zig build -Doptimize=ReleaseFast

zig build run \
  -Doptimize=ReleaseFast \
  -- --count 1000 \
  --worker 400

Security

Local means local.

✓

Private keys never need to leave your machine.

EVM does not connect to a blockchain or check wallet balances. Generated private keys are sensitive secrets and should be treated like a password vault.

  • Private keys come from std.crypto.random.
  • Randomness is backed by the operating system.
  • No RPC or blockchain connection is required.
  • Never commit generated wallets to Git.
  • Never upload or paste private keys into public services.
Under the hood

Small stack. Serious crypto.

The project keeps its cryptographic stack focused and transparent instead of hiding everything behind a large framework.

Z

Zig

Fast native compilation, predictable memory usage and lightweight concurrency.

K

Keccak-256

Ethereum-compatible hashing for deriving wallet addresses from public keys.

S

secp256k1

OpenSSL-backed elliptic curve cryptography used by Ethereum accounts.
