Modes

Three ways to generate.

Pick the mode you need. Everything runs locally on your machine.

01

Normal

Generate regular EVM wallets quickly using secure operating-system randomness.

02

Vanity

Generate addresses matching up to 10 hexadecimal characters after 0x or at the end.

03

Exclusion

Exclude unwanted hexadecimal characters such as b,6,f from generated addresses.

Quick Start

Up and running in seconds.

Clone the project, install dependencies and start generating. 

$ git clone https://github.com/iSreyanshu/Wallets.git
$ cd Wallets
$ chmod +x install.sh run.sh
$ ./install.sh
$ ./run.sh
Performance

Built for parallel generation.

A reusable Zig thread pool handles wallet generation efficiently. Worker count can be customized when running the tool.

100× default workers per detected CPU core
10 maximum vanity hexadecimal characters
Local no blockchain or balance checks
Custom worker count
$ ./run.sh --count 100000 --worker 1000
Output

Simple CSV output.

Generated wallets are written to wallets.csv.

wallets.csv
address,private_key
023bcd...,0x...
Security

Your keys stay with you.

Private keys are generated locally using std.crypto.random, backed by operating-system randomness. The application does not connect to a blockchain or check wallet balances.

Private keys are generated locally.
Uses OpenSSL secp256k1.
Uses Ethereum Keccak-256.
No blockchain connection.
No balance checking.
Treat wallets.csv like a password vault.
