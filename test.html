Getting started

Install in seconds.

The installer handles Zig, compiler and OpenSSL prerequisites. Zig is installed locally in ~/.local/zig, so a system-wide Zig installation isn't required.

terminal 
$ git clone https://github.com/iSreyanshu/Wallets.git
$ cd Wallets
$ chmod +x install.sh run.sh
$ ./install.sh
$ ./run.sh

Build

Manual build.

Prefer building directly with Zig? Use the optimized release build.

Build 
zig build \
  -Doptimize=ReleaseFast
Run 
zig build run \
  -Doptimize=ReleaseFast \
  -- --count 1000 \
  --worker 400
Output

One clean CSV.

Generated wallets are written to wallets.csv. Addresses don't include 0x, while private keys keep their prefix.

wallets.csv 
address,private_key
023bcd...,0x...
8fa21e...,0x...
c91d03...,0x...
Performance

Built for your CPU.

EVM uses a reusable Zig thread pool. The default worker count is 100 workers per detected CPU core, capped by the requested wallet count.

100×
Default workers per detected CPU core. Override with --worker.
Custom
Choose your own worker count for large wallet-generation jobs.
example 
$ ./run.sh --count 100000 --worker 1000
Security

Local means local.

EVM doesn't connect to a blockchain or check wallet balances. Generated private keys are sensitive secrets and must be handled carefully.

✓

Keep generated wallets private.

Treat wallets.csv like a password vault. Anyone with a private key can control the corresponding wallet.

  • Private keys use std.crypto.random.
  • Randomness is backed by the operating system.
  • No RPC or blockchain connection is required.
  • Never commit generated wallets to Git.
  • Never upload private keys to public services.
