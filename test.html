Wallet Generator

A local evm wallet generator with normal, vanity and exclusion modes.

Quick Start

git clone https://github.com/iSreyanshu/Wallets.git
cd Wallets
chmod +x install.sh run.sh
./install.sh
./run.sh

The installer handles compiler, build and OpenSSL prerequisites. Zig installs locally in ~/.local/zig.

Modes

Each run opens an interactive menu and asks for the wallet count:

  1. Generate normal wallets.
  2. Generate vanity wallets by matching up to 10 hexadecimal characters.
  3. Generate wallets excluding a comma-separated list of hexadecimal characters (e.g. b,6,f).

Output written to wallets.csv (address has no 0x; private key keeps 0x prefix):

address,private_key
023bcd...,0x...
8fa21e...,0x...

Performance

Default pool size: 100 workers per detected CPU core (capped by wallet count).

./run.sh --count 100000 --worker 1000

Manual Build

zig build -Doptimize=ReleaseFast
zig build run -Doptimize=ReleaseFast -- --count 1000 --worker 400

Security

  • Private keys from std.crypto.random (OS backed).
  • wallets.csv contains spendable secrets — treat like a password vault.
  • Never commit, upload or paste private keys to chat or issues.
  • No blockchain connection or balance check.
