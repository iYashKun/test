Quick Explanations

1. Pointer Capture

When you call element.setPointerCapture(pointerId), that element keeps receiving pointer events even if the pointer leaves it.
Very useful for dragging, drawing, and custom controls.
Release with element.releasePointerCapture(pointerId).

2. Pointer Lock API

Hides the mouse cursor and gives you relative movement (movementX / movementY).
Perfect for first-person games and 3D cameras.
Request: element.requestPointerLock()
Exit: document.exitPointerLock() or press Escape.

3. event.code vs event.key

• event.code → physical key (always KeyA for the A key)
• event.key → character that was typed (a or A)
